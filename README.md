# 卡秀商务酒店（阿育王塔店）

这里保存酒店宣传网页和一套在前台电脑本机运行的房态小程序。酒店位于青海省玉树藏族自治州囊谦县。

## 宣传网页

双击根目录的 `index.html` 即可预览。页面适配手机和电脑，展示酒店实景照片。正式对外使用前，请将页面中的“请补充订房电话 / 微信号”替换为真实联系方式，并核对地址和照片。

## 前台房态程序

Windows 电脑安装 Python 3.10 或更高版本后，双击 `启动前台.cmd`，在本机浏览器打开。详细操作见 [简单版使用说明](frontdesk/简单版使用说明.md)。

程序配置了酒店的 13 间客房，支持按日期查看房型和房号、登记客源与房费、在房号卡片显示备注、给未入住的预订换房、修改和删除记录、区分线上/线下金额，以及备份。携程 eBooking 导出的 `.xls` 订单可按订单号去重，并为无冲突的未来订单自动分配房号、写入姓名备注；已手工登记但未关联的订单会留给前台核对。美团远期订单目前需要手工登记。满房提醒会指出日期和房型，但**不会自动登录携程、美团或调整平台库存**，前台仍需在平台核对、关房。

程序只监听本机地址 `127.0.0.1`，营业记录保存在本机 `frontdesk/data`。本仓库不包含真实订单、客人资料、营业数据库、备份文件或 Windows 免安装包。换电脑或升级时，请单独、安全地转移 `frontdesk/data`，不要上传到公开仓库。

2026-09-29 更新：取消或删除关联房号时同步释放导入订单在本机的房量，支持在平台订单里修改“保留几间”、取消单间和补全分房；旧表重新导入不会恢复本机已取消的间数。连住按完整入住/离店日期分配，已有短记录在无冲突时补齐；冲突明确提示，不覆盖其他客人。已入住记录不会因导入取消而被自动抹除。

默认每晚房费：标准间 196.24 元、大床房 178.64 元、高级观景 284.24 元、舒适观景 266.64 元，按每间 × 晚数自动计算；已人工修改的金额或确认的付款保留。新导入记录仍标为“未付”，请前台核对实际付款；默认房价不代表平台成交价或实际到账。金额用整数分计算。

## 测试

核心测试可运行 `python -m unittest discover -s frontdesk/tests -q`。需要使用自己的携程样本验证解析时，可设置环境变量 `KASHO_CTRIP_SAMPLE` 指向该文件；样本本身不要提交到仓库。
